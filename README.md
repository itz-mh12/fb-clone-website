FB Clone Website

A static clone of the Facebook homepage/login UI, built as a hands-on project while learning Git.

About

This project recreates the look and feel of Facebook's front-end using basic web technologies. It was built primarily to practice Git and GitHub workflows — initializing a repository, staging and committing changes, and tracking version history — rather than as a production application.

Tech Stack
HTML
CSS
JavaScript
Features
Facebook-style login/landing page layout
Responsive design elements
Basic styling to match Facebook's UI
What I Practiced
Setting up a local Git repository
Making commits and writing commit messages
Pushing to and pulling from a remote repository (GitHub)
Basic branching workflow
Getting Started
Clone the repository:
bash
   git clone https://github.com/<your-username>/fb-clone-website.git
Navigate into the project folder:
bash
   cd fb-clone-website
Open index.html in your browser.
